# Private Inbox

วางไฟล์หลักฐานการเทรดไว้ในโฟลเดอร์ย่อย:

- `screenshots/`
- `pdfs/`
- `chat/`

ไฟล์ภายในโฟลเดอร์เหล่านี้ถูก ignore จาก Git เพราะอาจมีข้อมูลทางการเงินส่วนตัว

แนะนำชื่อไฟล์:

```text
YYYY-MM-DD_platform_ticker_description.ext
```

ตัวอย่าง:

```text
2026-06-10_binance_btc_fills.png
2026-06-10_ibkr_statement.pdf
2026-06-10_chat_nvda_entry.txt
```
